One line, 118 characters — the pickup line a vending machine would use on a passing human:

> You don't need exact change — one look from you and my coil spins, my lights blink, and I drop my best snack for free.

A vending machine never gives anything for free — that is the whole point of the machine. So when this one waves off exact change and drops its best snack for nothing, that is the joke: the machine breaks its own rules for one passing human. First person all the way (my coil, my lights, I drop), built from the machine's own world — exact change, coil, lights, snack — and the punch lands on the last two words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
